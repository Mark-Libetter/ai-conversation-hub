# AI Conversation Hub · 小程序（伴随端）设计文档

> 版本：v0.1（demo）　日期：2026-08-06　状态：局域网模型已实现，中继模型为路线

## 1. 定位：为什么产品逻辑不一样

电脑版是**本地优先的深度工具**：原始对话只存在于用户电脑、只读、服务只绑定
`127.0.0.1`，重输入（搜索/标签/导出/归类）、大屏。

小程序跑在手机上，**够不到电脑里的原始数据**，也不适合重输入。因此它不是
"把电脑版搬小"，而是桌面 hub 的**轻量伴随端**：

- 电脑 = 唯一数据源 + 唯一计算中心（规则引擎、脱敏都在电脑侧）。
- 手机 = "瞥一眼 + 随手记"：看日报/待办、路上记一条想法回传。

一句话：**桌面做深度，手机做 glance 与 capture。**

## 2. 连接与隐私模型

### 模型一 · 局域网配对（已实现，默认关闭）

- hub 增加一个**默认关闭**的伴随端监听，绑定 `0.0.0.0:8766`（可配）。
- 开启时本地生成随机配对码（token），只在桌面（localhost）展示，可一键更换。
- 手机与电脑同 Wi-Fi，扫码/手填 `IP + 端口 + 配对码` 完成配对。
- 伴随端**只输出已脱敏的派生数据**（日报摘要、待办、搜索片段），
  原始消息正文永远不离开电脑；随手记回传写入 hub 的独立表。
- 请求必须带 `X-Hub-Token`（或 `Authorization: Bearer`），常量时间比较。

优点：零新基础设施、完全守住"本地优先"。缺点：离开同一网络不可用、无推送。

### 模型二 · 加密中继（路线，未实现）

- hub 仅在用户开启时，把 **E2E 加密的派生摘要**推到一个小中继；
  手机 anywhere 拉取、可做每日推送；随手记加密回传。
- 原始对话仍不离电脑；过网的只有加密派生数据。
- 需引入 relay 与密钥管理，放在模型一验证价值之后。

### 微信平台的现实约束

微信小程序**生产环境**要求 ICP 备案的 HTTPS 域名，局域网 IP 走不通；
因此模型一更适合以**开发者工具/体验版 + 关闭域名校验**的方式演示，
或做成 PWA / 轻量 companion app。若坚持微信上架，只能走模型二（中继 + HTTPS）。
本 demo 以模型一 + 开发者工具运行。

## 3. 功能清单

### MVP（本 demo 已做）

1. **每日回顾卡片**：主线/焦点/已完成/待继续，可前后翻日。价值最高。
2. **待继续清单**：unfinished + next 去重列表，带来源标签，可一键复制。
3. **随手记**：手机记一条，联网写回 hub；离线自动暂存、回网补发。
4. **配对与连接态**：手填 IP/端口/配对码、测试连接、展示隐私说明。

### 二期

- 轻量搜索（只返回脱敏片段）。
- 收藏/状态快捷操作。
- 每日推送（依赖模型二或在家局域网定时）。

### 明确不做（与电脑版逻辑的分界）

完整对话阅读、导出、数据源配置、项目归类、主题设置——重活留在桌面。

## 4. 技术落点

- 新增 `companion.py`：独立 ThreadingHTTPServer，绑定 `0.0.0.0:8766`，
  token 鉴权；端点：
  - `GET /companion/health`（无需鉴权，探活）
  - `GET /companion/daily?day=`（脱敏日报）
  - `GET /companion/pending?day=`（待办）
  - `POST /companion/capture` / `GET /companion/captures`（随手记）
- 复用 hub 的 `daily_summary()` 规则引擎，`slim_daily()` 截断字段，
  保证隐私策略只有一份。
- 管理面（仅 localhost）：`GET/POST /api/companion`（启停、换码、返回 LAN IP）。
  桌面「设置 → 伴随端」卡片提供开关与配对码展示。
- 随手记存 `hub_notes.sqlite` 新表 `companion_captures`，与原始数据分离。
- 小程序在 `miniapp/`：原生 WXML/WXSS/JS，四页（回顾/待继续/随手记/连接），
  `project.config.json` 中 `urlCheck:false` 便于开发者工具局域网调试。

## 5. 运行 demo

1. 电脑启动 hub：`python server.py`（或 launcher）。
2. 浏览器打开 `http://127.0.0.1:8765` → 设置 → 伴随端 → 勾选「开启伴随端」，
   记下展示的 `IP:端口` 与配对码。
3. 微信开发者工具导入 `miniapp/` 目录（appid 可留空用测试号），
   在「详情 → 本地设置」勾选「不校验合法域名…」。
4. 小程序「连接」页填入 IP/端口/配对码 → 测试连接 → 成功后即可看回顾/待办/随手记。

## 6. 安全复核要点

- 伴随端默认关闭；开启需桌面显式操作。
- token 仅 localhost 展示/返回，LAN 上只接受持 token 的请求。
- 派生数据截断（标题 80 / 条目 200 / 概览 400 字符），不含完整正文。
- 随手记为新增独立表，不触碰任何原始 agent 数据库（仍只读）。

📝 配置指南（小白点我，5 分钟接通免费模型）

本工具需要一个大模型来做「每日回顾 / 对话总结」。下面三条路任选一条，推荐方案 A，最简单稳定。

方案 A · Groq（推荐，免费 1000 次/天）

  1. 打开 console.groq.com，用邮箱免费注册（不用信用卡）
  2. 左侧 API Keys → Create API Key，复制 gsk- 开头的密钥
  3. 回到这里：服务预设选「自定义」→ 接口地址填 https://api.groq.com/openai/v1 → 密钥粘贴 → 点「读取模型列表」
  4. 选 llama-3.3-70b-versatile（质量好）或 llama-3.1-8b-instant（最快），保存即可

提示：Groq 的 Cloudflare 会拦截非浏览器请求，本工具已处理（v0.20.4+）。若仍报 403，请升级到最新版。

方案 B · FreeLLMAPI（本地聚合，全免密钥）

  1. 下载安装 FreeLLMAPI 桌面版，打开后常驻托盘
  2. 这里：服务预设选「FreeLLMAPI」→ 自动填好 http://127.0.0.1:31415/v1
  3. 密钥填统一 key（FreeLLMAPI 安装后自动生成，在它的面板里查看，freellmapi- 开头）
  4. 模型选 auto（自动在免密钥源间择优），保存

提示：FreeLLMAPI 内置的免密钥源（OVH/kilo）有限速，连发会卡几分钟。重度使用建议走方案 A。

方案 C · 想用 DeepSeek 模型（已预置，给 key 即用）

  1. 打开 opencode.ai/zen，用 GitHub 账号登录，复制你的 Zen API Key
  2. 回到这里：服务预设选「OpenCode Zen（免费 DeepSeek）」→ 接口地址自动填好
  3. 密钥粘贴 Zen Key → 点「读取模型列表」→ 选 deepseek-v4-flash-free（免费）

全程免费、无需信用卡。若想要更强的 deepseek-v4-pro，同一接口直接选即可。
